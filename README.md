# Speedrun Timer

Клиентский мод-таймер для спидранов: **NeoForge 26.3**.

В углу экрана две строки, как на спидран-оверлеях:

```
RTA: 4:23:27.658
IGT: 3:39:34.119
```

RTA идёт по реальному времени, IGT считается по тикам мира и замирает вместе с ним
(пауза, `/tick freeze`, лаги). Подложки нет — только текст с тенью, обзор не закрывает.

## Установка

- Minecraft 26.3, NeoForge 26.3.0.101+, Java 25
- jar из [Releases](https://github.com/Ap4kG/SpeedrunTimer/releases) — в папку `mods`
- мод клиентский, на сервер его ставить не нужно

## Клавиши

F8 - сброс и запуск
F9 - пауза / продолжить
F10 - скрыть / показать

Переназначаются в «Настройки → Управление → Speedrun Timer».

## Позиция и настройки

Таймер перетаскивается мышью: открыть чат (T), навести на него — появится рамка,
зажать ЛКМ и тянуть. При отпускании угол и отступы сами пишутся в
`config/speedruntimer-client.toml`, там же `scale`, цвета, миллисекунды и скрытие на F3.

Если в углу висит миникарта, проще перетащить таймер ниже, чем править конфиг руками.

## Сборка

```powershell
.\gradlew.bat build
```

Готовый jar — `build/libs/speedruntimer-1.0.1.jar`. Запуск из среды разработки —
`.\gradlew.bat runClient`.
